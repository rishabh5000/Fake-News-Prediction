 Fake News Detection using NLP
This project focuses on detecting fake news using Natural Language Processing (NLP) techniques, vectorization methods, and machine learning models. It includes model evaluation and a user-friendly Streamlit app for real-time predictions.

🔍 Key Features
Text Preprocessing: Tokenization, stopword removal, and lemmatization.

Vectorization: Applied TF-IDF to convert text into numerical format.

Imbalanced Data Handling: Used SMOTE oversampling for balancing fake vs. real news.

Model Comparison: Trained and evaluated multiple models including Logistic Regression and Support Vector Machine (SVM).

Evaluation Metrics: Checked performance with confusion matrix, ROC-AUC, and accuracy scores.

Best Model Accuracy: Achieved 95.6% accuracy on the test set.

🚀 Deployment
Deployed on Streamlit for an interactive interface.

Users can input custom news headlines/text to check for authenticity in real-time.
